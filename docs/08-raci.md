# مصفوفة المسؤوليات (RACI) — Iqama Screener

**يجب تعبئة الأسماء قبل تشغيل الطيار.** R = ينفّذ، A = يُحاسَب (واحد فقط لكل صف)، C = يُستشار، I = يُبلَّغ.

## الأدوار
| الدور | الاسم | البريد / الجوال |
|---|---|---|
| مالك النظام (System Owner) | *(يُعبَّأ)* | |
| مالك البيانات (Data Owner) — الشركة الطالبة | *(يُعبَّأ)* | |
| مسؤول الأمن (Security Owner) | *(يُعبَّأ)* | |
| مسؤول الخصوصية / الامتثال (PDPL) | *(يُعبَّأ)* | |
| المشغّل التقني (DevOps) | *(يُعبَّأ)* | |
| المراجعون (Reviewers) | *(يُعبَّأ)* | |

## الإيقاعات
- **أسبوعياً:** مراجعة خطة الجاهزية (30 دقيقة) — مالك النظام.
- **شهرياً:** تمرين استعادة + مراجعة سجل التدقيق (الكشف، تغيير القواعد، الحذف) — مسؤول الأمن.
- **ربع سنوياً:** مراجعة صلاحيات المستخدمين وجدول الاحتفاظ — مالك النظام + الخصوصية.
