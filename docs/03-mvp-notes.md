## 3. قرارات هندسية اتُّخذت أثناء البناء (تحتاج علمك)

1. **محرك OCR للتحقق: EasyOCR بدل PaddleOCR.** مستضيف نماذج Paddle محجوب من بيئة البناء (سياسة شبكة). `PaddleProvider` مكتوب ومسجَّل كافتراضي في `rules.yaml`، لكنه **لم يُختبر هنا**. على جهازك: جرّب الاثنين واختر الأدق (`IQAMA_OCR_PROVIDER`).
2. **ثقة الأرقام ذات الـ checksum.** رقم من 10 خانات ببادئة صحيحة و Luhn ناجح يُمنح ثقة ≥ 0.86 حتى لو كانت ثقة OCR أقل — هذا ما يجعل «الكفالة الفردية تُرفض مباشرة» (D5) دون تدخل. أرقامكم الستة الحقيقية كلها تجتاز Luhn، ما يؤكد أن الهوية الوطنية والإقامة والرقم الموحد تستخدمه.
3. **المهنة والجنسية:** المطابقة التامة مع القاموس ترفع الثقة إلى 0.80 فقط — **أقل من عتبة الرفض الآلي (0.85)** عمداً. أي رفض بسبب المهنة من قراءة OCR ضعيفة يذهب للمراجعة لا للرفض.
4. **الصورة الرديئة تتقدّم على كل شيء:** جودة < 0.45 → مراجعة، حتى لو ظهر «منتهية».
5. **الأسباب غير المؤكدة لا تُخفى:** عند الرفض، أي فحص راسب بثقة منخفضة يظهر في `review_triggers` ليراه المراجع والتقرير.
6. **الصور تُحذف بعد القرار النهائي** (افتراضياً)، وتبقى ما دامت الحالة في المراجعة.

## 4. حدود معروفة

- **جودة لقطات الشاشة (~700 بكسل):** الحقول الحرجة تُقرأ لكن بثقة 0.5–0.7 → المراجعة كثيرة في البداية. صورة أصلية من الكاميرا/الماسح تحسّن ذلك مباشرة.
- **OCR غير حتمي تماماً:** فروق بكسلات طفيفة تغيّر بعض القراءات؛ المرور الرقمي الثاني والاستدلال الصفّي يعوّضان أغلبها.
- **`مكان العمل`** يُستخرج فقط عند وجوده على البطاقة (إصدارات مختلفة).
- **الهوية (MVP):** مفتاح API واحد + اسم المستخدم في ترويسة `X-Actor` للتدقيق. RBAC كامل في Phase 5.
- **Alembic:** المخطط يُنشأ بـ `create_all`؛ الترحيلات تُضاف عند أول تغيير في المخطط.
- لا كشف تزوير؛ لا تحقق من أنظمة الدولة (قيد أصيل — يُطبع في كل تقرير).

## 5. كيف تجرّبه

```bash
pip install -e ".[dev]" && pip install easyocr
uvicorn app.main:app --port 8000 &
streamlit run ui/streamlit_app.py
```
ارفع صورك → Process → Dashboard → Manual Review. جرّب تعديل `config/occupations.csv` من صفحة Rules وشاهد الإصدار يتغير.

## 6. ما أحتاجه لـ Phase 4

1. **20–50 صورة إقامة** متنوعة (كاميرا وماسح ولقطات شاشة) لقياس الدقة إحصائياً ومعايرة العتبات.
2. تجربتك لـ PaddleOCR على جهازك (مقارنة بـ EasyOCR).
3. أي مهن تريد بذرها كمؤهلة لتقليل المراجعات.
4. إجاباتك على Q20–Q23 إن اختلفت عن الافتراضات.
